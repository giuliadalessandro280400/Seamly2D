Detailed Description

The VToolScale class scales a set of objects relative to an origin point.

Horizontal (X) and vertical (Y) factors are independent formulas, so the operation follows size changes. A factor of 1 leaves that direction unchanged, 1.1 makes it 10% longer, a negative factor also mirrors.
