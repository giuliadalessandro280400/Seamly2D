Detailed Description

A piece of an AAMA DXF file (ASTM D6673). Coordinates are in millimetres, y up as in the file. layer 1 boundary (closed polyline) and texts layer 2 turn points (corners) layer 3 curve points layer 4 notches layer 7 grain line layer 8 internal lines
