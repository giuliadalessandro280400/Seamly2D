VToolAlign Class Reference

The VToolAlign class moves a group of objects so that point P lands on point T, then rotates the group around T so that the direction P->A follows the direction T->B (plus an optional extra angle). The group is not deformed. More...

Detailed Description

The VToolAlign class moves a group of objects so that point P lands on point T, then rotates the group around T so that the direction P->A follows the direction T->B (plus an optional extra angle). The group is not deformed.
