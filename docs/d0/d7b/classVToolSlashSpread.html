VToolSlashSpread Class Reference

The VToolSlashSpread class is the draft operation "slash and spread": the selected objects are cut by slashes from the edge to the hinge, evenly spaced, and opened by the spread (a length or a percentage of the edge). The result is a copy: the original objects do not change. The spread can be a formula, so it grades. More...

Detailed Description

The VToolSlashSpread class is the draft operation "slash and spread": the selected objects are cut by slashes from the edge to the hinge, evenly spaced, and opened by the spread (a length or a percentage of the edge). The result is a copy: the original objects do not change. The spread can be a formula, so it grades.
