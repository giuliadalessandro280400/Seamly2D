BaseLibrary::InsertResult BaseLibrary::insertBase ( VAbstractPattern *  doc,
const QString &  path,
const QPointF &  start,
const QSet< QString > &  knownNames,
const std::function< bool(const QString &)> &  isTaken 
)

Appends the draft blocks of the base at path to doc:

  • every id is moved above the highest id of the pattern;
  • a block with an existing name gets a number;
  • a point whose name is taken gets a number, and the formulas follow;
  • the base's variables the pattern lacks are copied;
  • the blocks are moved so the first base point lands on start (pattern units). knownNames are the measurement / variable names the pattern already has; any other name used by a formula is reported in InsertResult::missing. isTaken tells whether a point name is already used in the pattern.
