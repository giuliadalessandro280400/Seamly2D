Detailed Description

The Deformation class moves any point as the tied points moved: moving least squares (Schaefer, McPhail, Warren 2006). One tie: the whole moves. Two: it moves, turns and grows. Three or more: it also changes shape, smoothly, each point following mostly the ties near it.
