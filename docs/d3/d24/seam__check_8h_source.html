46/**
47 * @brief The SeamCheck class walks a piece along another one, like sliding one paper pattern on the other.
48 *
49 * 1. the user chooses the base piece,
50 * 2. a point of the checked piece and the point of the base piece it starts from,
51 * 3. moving the mouse along the base piece the checked piece rolls along it, so that both contours touch at the same
52 * walked length. Space walks the other way. A click stops it so the points can be corrected (on the real piece),
53 * 4. Separate puts the piece back in its place.
54 *
55 * Only the view of the checked piece changes while checking: its position in the file is not touched.
56 */
