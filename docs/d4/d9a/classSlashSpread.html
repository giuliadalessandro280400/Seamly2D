Detailed Description

The SlashSpread class opens a part of a pattern like slashing the paper from the edge to a hinge point and spreading it.

The slashes go from the hinge to points evenly spaced along the edge to open. Each object is in one of the sections between the slashes and turns around the hinge with its section: every slash opens so that the edge gets longer by the same amount. One part stays where it is: the one at the first point of the edge, the one at the last point, or the middle (both sides open). A curve cut by a slash is redrawn as one smooth curve through its opened pieces.
