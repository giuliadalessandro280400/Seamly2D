Detailed Description

The SeamCheck class walks a piece along another one, like sliding one paper pattern on the other.

  1. the user chooses the base piece,
  2. a point of the checked piece and the point of the base piece it starts from,
  3. moving the mouse along the base piece the checked piece rolls along it, so that both contours touch at the same walked length. Space walks the other way. A click stops it so the points can be corrected (on the real piece),
  4. Separate puts the piece back in its place.

Only the view of the checked piece changes while checking: its position in the file is not touched.
