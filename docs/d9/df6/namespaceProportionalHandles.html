Detailed Description

Proportional handles

Normally the length of a curve handle is a fixed value. When the pattern is graded the end points move but the handles keep their length, so a curve drawn nicely in one size looks too round or too square in the others.

With proportional handles a curve remembers its chord (the distance between the two end points of a segment) in the size where it was edited. The stored handle lengths belong to that reference chord; in every other size they are multiplied by currentChord / referenceChord. The handle angles do not change.

Simple curves store the reference in the attribute "refChord", curve paths store one value per segment in "refChords" (separated by ';'). Values are in pattern units.
